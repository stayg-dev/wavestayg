# 객실 요금표 반영 (2026-09-18)

사용자가 제공한 객실 요금표와 “표의 금액 그대로 적용” 지시를 기준으로 한다.
기존 58,000원 미리보기 가격, 세금·봉사료 10% 가산, SUMMER25 15% 할인은 제거했다.
세금 포함 여부에 대한 별도 문구를 추정하지 않고 표의 금액을 그대로 합산한다.

- `src/lib/rooms.ts`: 11개 타입의 일~목 / 금 / 토·공휴일 전일 요금, 기존 객실 ID 유지.
- `src/lib/booking.ts`: 체크인일부터 체크아웃 전날까지 각 날짜별 요금 합산. 공휴일 전일이 금요일 요금보다 우선한다. 공휴일 당일 자체는 다음 날이 공휴일인지와 요일에 따라 판단한다.
- 기존 객실 기준 인원 2인을 유지한다. 8세 이상 중 기준 인원을 초과한 인원에 1인 1박 22,000원을 부과한다. 1~7세는 인원 추가요금 무료이며 기존 객실 최대 인원에 포함한다.
- 인원 추가요금에 침구가 포함된다. 별도 신청한 추가 침구만 1세트 1박 22,000원으로 합산한다.
- 얼리체크인·레이트체크아웃은 시간당 11,000원, 프런트 사전 요청 사항으로 안내한다. 승인되지 않은 시간을 예약 총액에 자동으로 넣지 않는다.
- 예약 미리보기는 금액 명세를 저장한다. 조회 시 현재 요금으로 재계산하지 않는다. 명세가 없는 기존 미리보기 기록은 저장된 총액만 표시한다.
- 실제 재고·결제 연동은 기존과 같이 미리보기 상태다.

## 공휴일 데이터

`src/lib/holidays.ts`에 2026~2027년의 공휴일과 대체공휴일, 2026년 전국동시지방선거일을 관리한다. 2027-12-31 숙박 요금 판별에 필요한 2028-01-01도 포함한다. 일요일은 요금표의 일~목 구분을 따르며 별도 공휴일 목록에 추가하지 않는다.

확인 범위 밖의 숙박일은 임의로 평일 요금을 계산하지 않고 프런트 문의를 안내한다. 새 월력요항 발표 시 목록과 지원 종료일을 함께 갱신하고, 임시공휴일 지정 시 해당 날짜를 추가한다.
